# 终末地洛茜本机模型

## 用途与文件树

此集合提供本机可选的洛茜中文 GPT-SoVITS 音色，不属于公开部署的默认依赖。运行文件放在项目根目录下：

```text
models/gpt-sovits/
├─ 终末地-中文.md
└─ 终末地-中文/
   ├─ V2ProPlus/洛茜/
   │  ├─ 终末地_洛茜-e15.ckpt
   │  ├─ 终末地_洛茜-e20.ckpt
   │  ├─ 终末地_洛茜_e16_s400.pth
   │  ├─ 终末地_洛茜_e20_s500.pth
   │  ├─ 【默认】… .wav
   │  └─ 头像.jpg
   └─ V4/洛茜/
      ├─ 洛茜-e10.ckpt
      ├─ 洛茜_e12_s408_l32.pth
      ├─ 洛茜_e16_s544_l32.pth
      ├─ 【默认】… .wav
      └─ 头像.jpg
```

`【默认】… .wav` 是同一段参考音频在两个版本目录中的副本；其完整文件名、大小和 SHA-256，以及上述全部 11 个运行文件的校验值见 [洛茜模型锁文件](../../config/luoxi-model.lock.json)。本机另有 `素材/洛茜/` 来源页面快照与试听素材，它们不是服务运行的必要文件，也不由下载脚本导入。

## 来源与版本边界

- 用户提供的来源：[AI Hobbyist 交流社区洛茜 V4 / V2ProPlus 帖](https://www.ai-hobbyist.com/thread-160048-1-1.html)。本机保存的页面快照也指向该帖。
- 帖子标题注明“回复获取”；目前只有论坛页面地址，没有可公开访问的模型包直链、固定上游提交或原始压缩包校验值。因此锁文件固定的是 2026-10-22 本机运行文件的字节内容，不声称锁定了上游发布版本。
- 获取与使用模型前应核对来源页面的许可和使用条件。本仓库不分发权重、参考音频或头像，不把来源链接解释为再分发许可。

## 未纳入 Git 的原因

11 个运行文件合计 964,427,244 字节，其中多个权重超过 100 MiB。它们只保存在本机被忽略的实际模型目录；Git 记录本说明、锁文件和准备脚本。

## 下载与重建

先按来源帖取得包含 V4 与 V2ProPlus 运行文件的 ZIP 包。论坛页面本身不能作为 `--url` 参数。然后在项目根目录运行独立准备脚本 [download_luoxi_model.py](../../tools/download_luoxi_model.py)：

```powershell
python tools/download_luoxi_model.py --archive C:/path/to/V4.zip --archive C:/path/to/V2ProPlus.zip
```

如果取得的是模型 ZIP 的 HTTPS 直链，可重复传 `--url`，脚本先下载到忽略的 `~temp/downloads/luoxi/`，再从包内按内容哈希找出所需文件。它不会根据不可信的 ZIP 路径直接解压，也不会覆盖已有模型目录。安装前须匹配锁文件内全部运行文件的大小和 SHA-256；失败的暂存内容留在 `~temp/model-imports/` 供检查，不会被脚本物理删除。现有本机目录可用以下命令复核：

```powershell
python tools/download_luoxi_model.py --verify-existing
```

新来源包若与本机快照不一致，应先核实上游版本和文件来源，再决定是否更新锁文件；不能跳过校验继续安装。安装后还需通过正式模型选择接口实际加载 GPT/SoVITS 并完成参考音频试读，才能标为可用。
