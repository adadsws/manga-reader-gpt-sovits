# 鸣潮中文本机模型

## 用途与文件树

此集合让电脑端 Reader 在 Android 模型列表中选择鸣潮中文 GPT-SoVITS 角色；`菲比_ZH` 是默认音色。模型实际文件位于本机，不纳入仓库。下载并准备后的示例结构：

```text
models/gpt-sovits/
├─ 鸣潮-中文.md
└─ 鸣潮-中文/
   └─ v4/
      ├─ 吟霖_ZH/
      │  ├─ 吟霖_ZH-e10.ckpt
      │  ├─ 吟霖_ZH_e10_s370_l32.pth
      │  ├─ 【默认】… .wav
      │  ├─ 角色头像.png
      │  ├─ reference_audios/中文/emotions/【默认】… .wav
      │  ├─ train.log
      │  └─ .source.json
      └─ 其余已安装角色_ZH/
```

上游 ZIP 的目录和文件原样保留。`.source.json` 是本机安装清单，记录包哈希与解压文件的大小、SHA-256。准备脚本另将同一角色的默认参考 WAV 复制到角色根目录，并从网上下载经角色名核对的头像；原始嵌套 WAV 不移动。找不到可靠头像时，Android 模型列表使用内置图标。

## 本地重建

在项目根目录运行独立脚本 [download_mingchao_zh.py](../../tools/download_mingchao_zh.py)：

```powershell
python tools/download_mingchao_zh.py
```

脚本只下载锁文件中的 57 个中文角色 ZIP，以大小和 SHA-256 校验，检查每包有 GPT `.ckpt`、SoVITS `.pth` 与参考 `.wav`，再安装到 `models/gpt-sovits/鸣潮-中文/v4/`。ZIP 文件名按上游使用的 GBK 解码。缓存与 `progress.jsonl` 位于忽略的 `~temp/downloads/mingchao-zh/`；中断后再次运行会尝试续传，已安装角色会逐文件校验，不覆盖。单个角色失败时，脚本将阶段、错误和堆栈写入进度日志并继续其他角色；再次执行默认跳过上轮错误项，检查原因后加 `--retry-errors` 重试。共享来源不可用时脚本停止。

只安装默认角色可使用 `--only 菲比_ZH`；校验单角色可追加 `--verify-existing --only 菲比_ZH`。安装后运行 [prepare_mingchao_profiles.py](../../tools/prepare_mingchao_profiles.py)，为已安装角色补齐根层参考音频与可用头像：

```powershell
python tools/prepare_mingchao_profiles.py
python tools/prepare_mingchao_profiles.py --verify-existing
```

准备脚本不覆盖已有文件，下载头像前检查固定大小和 SHA-256。当前 57 个完整模型中 34 个有经身份核实的头像，余下 23 个 NPC 等角色没有可靠来源，沿用应用默认图标。安装后模型初态是“未验证”；电脑服务启动后会在后台逐项真实加载 GPT/SoVITS 并用同角色参考音频试读，成功才标为“可用”，失败则保留具体原因。Android 模型目录显示每个角色的实际状态与批次进度。

运行模型文件总量过大，因此实际权重、参考音频、头像、上游日志和下载缓存均不纳入 Git；Git 只记录本说明、锁文件与准备脚本。
